# PVC Global 2.0

Modern study-abroad consultancy website.

## Run locally

From this folder:

```bash
python3 -m http.server 5500
```

Then open:

`http://localhost:5500/fronntend/`

## Updated in this version

- Modern IDP-inspired visual direction with PVC Global branding
- Fixed/stable shared CSS and JavaScript paths
- Dynamic glass navbar that changes on scroll
- Mobile responsive navigation
- Smooth scrolling and scroll-reveal animations
- Photo-based hero and destination backgrounds
- Modern destination cards for UK, Australia, Canada, USA, Germany and Italy
- Refined cards, buttons, forms, FAQ and CTA sections
- Shared JavaScript for forms and FAQ accordion

The photo backgrounds use remote Unsplash images, so an internet connection is needed for those photographs to appear while running locally.
